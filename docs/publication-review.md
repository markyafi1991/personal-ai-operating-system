# Documentation publication review

**Version 3.0** · 2026-11-13

## Definition of done

Replace the stale main narrative and illustrative examples; describe the current
vault relationships; assign evidence/status to capability claims; retain exact
technical release pins; keep private records out; update the existing PR and
read back the new head, description and visible change comment. No merge,
private export, source policy amendment, runtime change or PDF publication.

## Source and privacy method

The refresh uses selected private conventions and engineering source to author
new public summaries. No actual vault note bodies, client records, private task
or learning histories, credential files, internal grant records or source captures
are copied. The miniature notes and examples are newly invented. Private evidence
records are kept separately from this public tree.

Mechanical checks validate local document links and example metadata, scan changed
payloads for credentials/private identifiers/obsolete claims, and bind the reviewed
file bytes in a local manifest. A semantic pass checks scope, ownership and the
difference between implemented code, operating rules and acceptance targets.
Signature scans cannot establish absence of all sensitive material by themselves.

## Review authority and limits

This is a documentation-only change: Codex is the author and performs the source,
privacy, citation and link checks. No implementation or access policy is changed.
The existing independent RELEASE receipt remains bound to the earlier technical
evidence snapshots; it is not advertised as approval of this revised prose.
Owner review and merge of the open PR remain pending. No new independent AI
review or live deployment audit is claimed for the refresh.
